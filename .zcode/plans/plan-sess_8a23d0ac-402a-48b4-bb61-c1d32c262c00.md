# Peningkatan UI/UX Menyeluruh LokaQuest — Elegan, Interaktif, Penuh Animasi

## Context

Tema LokaQuest sudah mapan (warm-paper, nila-indigo, sogan-gold, Fraunces, motif batik-grid/tenun) dengan toolkit animasi yang baik (Reveal, Tilt3D, CountUp, Confetti) — tapi hanya dipakai di ~30% halaman. Audit menemukan: halaman unggulan tanpa animasi (`/encyclopedia/[slug]`, `/leaderboard`, `/player/dashboard`, `/player/profile`, semua educator, sebagian besar admin), mobile menu & lightbox tanpa transisi, `CountUp` hanya di home, footer hanya di home, `ThemeToggle` dibuat tapi tak pernah dirender (dark mode tak terjangkau), tidak ada `loading.tsx`, `alert()/confirm()` native di admin.

**Prinsip:** identitas tema DIPERTAHANKAN (bukan diganti); semua animasi transform/opacity 150–550ms, dihormati `prefers-reduced-motion` (kill-switch global sudah ada), tanpa emoji-ikon, kontras terjaga.

## Layer 1 — Fondasi Design System

**`src/app/globals.css`** — tambah keyframes & utilities (semua di.theme):
- `animate-scale-in`, `animate-fade-in`, `animate-pop` (badge/bubble), `animate-slide-up`
- `.text-gradient` (headline serif nila→gold via bg-clip-text), `.bg-warm-wash` (radial hero wash), `.hover-lift` (translateY + shadow-raised), `.btn-sheen` (kilau sweep saat hover), `.glow-gold` (rarity legendary), `.card-sheen` (sheen di kartu hero)
- `.prose-ensiklopedia` (drop-cap Fraunces, spasi baca, h2 ornament) untuk artikel panjang

**`src/app/tailwind.config.ts`** — daftarkan keyframes baru + easing `out-expo`.

## Layer 3 — Halaman (per gelombang, edit terarah bukan rewrite)

**A. Publik inti:**
- `leaderboard`: podium top-3 (medali gold/silver/bronze, CountUp XP, Reveal), baris stagger + rank chip
- `missions`: chip warna per difficulty (pemula/menengah/lanjut), PageHeader
- `regions/[slug]`: lightbox animasi (backdrop fade + scale-in), PageHeader
- `komunitas`, `jelajahi`, `tentang`, `sumber`: PageHeader + polish hover; `jelajahi` hapus `ID: uuid` mentah; `asisten`: bubble chat dibedakan (user primary vs AI card) + typing dots + chips hover
- `explore`: Reveal grid + toggle segmen transisi

**B. Ensiklopedia (halaman unggulan):**
- `encyclopedia/page.tsx`: hero fade-up + stagger kartu, raw input → ui/Input
- `encyclopedia/[slug]`: **ReadingProgress + TOC scrollspy sticky + `.prose-ensiklopedia` + Reveal per section + hover zoom gambar**
- `explore/regions/categories`: stagger + image hover zoom; kategori render `cover_image_url`
- `collections`/`favorites`: Skeleton loading + progress bar animasi + hapus dengan fade-out
- `search`: hasil stagger + pagination pill

**C. Player:**
- `dashboard`: CountUp semua metrik + XP bar shimmer + stagger kartu + badge pop-in
- `profile`: stats CountUp + hover treatment (0 hover saat ini)
- `assessments/[id]`: transisi antar soal (key + animate-slide-up); `assessments`: kartu hover
- `collection`: glow rarity legendary + stagger

**D. Educator:** `dashboard` & `analytics`: Reveal + CountUp + bar delta pre→post (CSS) + rapikan CTA mati (jadi disabled "Segera hadir" / link analitik)

**E. Admin:** PageHeader konsisten + Reveal daftar + CountUp (dasbor & analitik); `missions-client` & `submissions-client`: alert/confirm → Toast/ConfirmDialog; `admin/encyclopedia*`: Button/Card/EmptyState yang benar; form artikel baru dibungkus Card per seksi

**F. Auth:** login/register animasi entrance (panel brand fade + form slide); `forgot-password` dapat panel brand batik-grid; `callback` spinner + logo

**G. Global:** `loading.tsx` untuk (public), encyclopedia, player, educator, admin (skeleton bertema); footer semua halaman publik
